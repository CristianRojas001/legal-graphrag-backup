# Refinement

Documents in this folder capture the plan and sprint for improving Legal GraphRAG answer quality, citation grounding, and evaluation.

- `01_RAG_QUALITY_PLAN.md`: Technical plan (safe/strategic changes, gating/grounding, retrieval tightening, evaluation).
- `02_REFINEMENT_SPRINT_PLAN.md`: Detailed sprint to implement and verify the fixes.
- `03_V1_1_SPRINT_PLAN.md`: V1.1 sprint plan for multi-query retrieval and judge pipeline.



All refinement work should align with the chat quality North Star and rules in [docs/Chat Evaluation/](../Chat%20Evaluation/NorthStarGoal.md) and follow the evaluation runbook [RUN_EVAL_RUNBOOK.md](../Chat%20Evaluation/RUN_EVAL_RUNBOOK.md).
